UI

게임 UI 버튼 상호작용 & 모핑 샘플 20선

클릭 · 길게 누르기 · 마우스 이동으로 형태 변형(Morph)과 피드백을 테스트하세요

#01 · STAMP MORPH 물류/채용

고용 승인 도장 변신

버튼이 납작한 붉은 고무도장 인장으로 변형되며 쾅 찍힙니다.

#02 · DISPATCH MORPH 물류/출하

트럭 상차 출발 변신

클릭 시 버튼이 화물 트럭 캡슐로 줄어든 뒤 우측으로 출발합니다.

#03 · HOLD TO UNLOCK 홀드/안전

잠금 덜그럭 & 홀드 해금

짧게 누르면 자물쇠가 덜그럭 흔들리고, 0.8초 꾹 누르면 고리가 열립니다.

#04 · JELLY SQUISH 물리 탄성

젤리 탄성 & 코인 팝

가로로 찌그러졌다가 튕겨 오르며 금화 파티클을 뿜어냅니다.

#05 · BOX SEALING 물류/포장

택배 상자 테이핑 봉인

버튼이 크라프트 상자 형태로 변하고 중앙에 포장 테이프가 감깁니다.

#06 · LEVEL UP MORPH 물류/강화

업그레이드 수치 모핑

클릭할 때마다 버튼 폭과 레벨 뱃지가 팽창하며 등급이 상승합니다.

#07 · SIGNATURE MORPH 물류/계약

계약서 자동 서명 모핑

버튼이 서명 용지로 펼쳐지며 만년필 싸인이 그려진 뒤 체결됩니다.

#08 · SPEED CYCLE 형태 모핑

1x → 2x → 3x 배속 아이콘 루프

1배속은 정지, 2·3배속 전환 시 왼쪽 플레이 삼각형만 연속 슬라이드 루프됩니다.

#09 · ALERT EXPAND 형태 모핑

병목 경고 뱃지 확장

작은 원형 아이콘이 클릭 시 긴급 경고 배너 알약으로 펼쳐집니다.

#10 · LIQUID FILL 형태 모핑

리퀴드 차오름 버튼

아래에서부터 황금빛 게이지가 차오르며 수면 기준으로 글자 색상이 분할 반전됩니다.

#11 · MAGNETIC PULL 물리 탄성

자석 인력 추종 버튼

마우스 커서를 가까이 대면 버튼이 자석처럼 끌려오며 기울어집니다.

#12 · SPLIT CONFIRM 형태 모핑

해고 2단계 분할 모핑

실수 방지를 위해 클릭 시 [확인]과 [취소] 두 버튼으로 갈라집니다.

#13 · COIN ABSORB 물류/수익

매출 수령 동전 압축

직사각 버튼이 동그란 금화로 압축된 뒤 상단으로 흡수됩니다.

#14 · CONVEYOR BELT 물류/설비

컨베이어 레일 가동 모핑

정지된 회색 바가 산업용 안전 줄무늬 레일로 변하며 회전합니다.

#15 · 3D CARD FLIP 형태 모핑

3D 뒤집기 스탯 스위치

클릭 시 Y축으로 180도 회전하며 뒷면의 상세 수치를 보여줍니다.

#16 · ICON TO PILL 형태 모핑

정사각 → 완료 알약 모핑

44px 정사각형 버튼이 길쭉한 초록 알약으로 늘어나며 체크됩니다.

#17 · RECEIPT POP 형태 모핑

영수증 돌출 포스기 버튼

버튼 상단 틈새에서 미니 정산 영수증 종이가 쏙 올라옵니다.

#18 · GOOEY SWITCH 물리 탄성

점성 탄성(Gooey) 토글

원형 노브가 이동하는 순간 물방울처럼 길게 늘어났다가 복원됩니다.

#19 · EXPAND DOCK 형태 모핑

원형 '+' → 퀵 툴바 확장

동그란 추가 버튼이 가로형 서브 메뉴 바로 매끄럽게 펼쳐집니다.

#20 · COOLDOWN MORPH 홀드/안전

스킬 사용 → 원형 쿨타임

발동 즉시 원형 타이머(3초)로 수축했다가 완료 후 복원됩니다.

#21 · LOCK RATTLE & OPEN 잠금/해금

잠금 덜그럭 & 열쇠 해금

잠금 버튼 클릭 시 자물쇠만 덜그럭 흔들리고, 열쇠로 해금 시 고리가 열립니다.

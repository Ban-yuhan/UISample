# 버튼 인터랙션(ButtonScene) UI 리소스 제작 요청서

버튼을 누를 때의 모션 10종과 부가 이펙트를 보여주는 쇼케이스 씬에 쓸 리소스 제작 요청입니다.
버튼 모션 자체는 전부 코드(DOTween)로 움직이기 때문에, **필요한 건 버튼 판 이미지, 이펙트 입자, 아이콘뿐입니다.**
현재는 코드로 그린 원/둥근 사각형 하나로 모든 걸 대신하고 있고, 이 요청서의 이미지로 교체합니다.

- 구현 코드: `Assets/Scripts/UI/UIButtonFeedback.cs`, `Assets/Scripts/UI/Effects/*.cs`
- 씬: `Assets/Scenes/ButtonScene.unity`

---

## 1. 공통 규칙

| 항목 | 내용 |
|---|---|
| 포맷 | PNG, 투명 배경 (RGBA) |
| 색상 | **전부 순백(#FFFFFF) 단색 + 알파만 사용.** 버튼마다 색이 달라서(옐로우, 브라운, 오렌지, 네이비 등) 색은 코드에서 틴트합니다. |
| 안티앨리어싱 | 가장자리는 부드럽게 (알파 그라데이션). 계단 현상 없을 것 |
| 여백 | 이미지 가장자리 1~2px는 투명으로 비울 것 (잘림 방지) |
| 크기 | 아래 각 항목의 **캔버스 크기를 정확히** 지킬 것 |
| 배율 | 특별한 언급이 없으면 **UI 기준 크기의 2배**로 그립니다. (UI 16px → 이미지 32px) |
| 파일명 | 아래 항목에 적힌 파일명 그대로 |

> 기준 해상도: 1920 × 1080 캔버스. 메인 버튼이 **380 × 115**, 서브 버튼이 **175 × 80 / 80 × 80(원형)**, 컨트롤 패널 버튼이 **295 × 44**입니다.

---

## 2. 버튼 구조 (구도 참고)

버튼 하나는 아래 3겹으로 되어 있습니다. 같은 이미지를 색만 바꿔서 겹칩니다.

```
        ╭──────── 글로우 (바깥 빛번짐) ────────╮
        │  ╭────────── 바디 ──────────╮        │
        │  │      배송 보내기         │        │  ← 바디: 버튼 본체 (눌리면 내려감)
        │  ╰──────────────────────────╯        │
        │  ╰══════════ 림(그림자) ════╯        │  ← 림: 바디와 같은 이미지, 9px 아래, 진한 색
        ╰──────────────────────────────────────╯
```

- **림/그림자, 카드 배경, 헤더**는 바디 이미지를 그대로 다시 씁니다. **별도 제작 불필요.**
- 레이어 순서 (아래 → 위): 림 → 바디 → 글로우 → 이펙트(테이프·레이저) → 라벨

## 3. 제작 리소스

### A. 버튼 판

#### A-1. 둥근 사각 바디 — `btn_body_rounded.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **128 × 128** |
| 형태 | 꽉 찬 **둥근 사각형** (사방 1px 여백) |
| 모서리 반지름 | **28px** (UI 기준 14px) |
| 9-slice Border | **상·하·좌·우 모두 32** |
| 용도 | 모든 사각 버튼 본체, 림, 카드 패널, 헤더 배경 |

- 내부는 균일한 흰색 (그라데이션, 하이라이트, 그림자 넣지 말 것)
- 380×115부터 295×44까지 늘려 쓰기 때문에 **모서리 4개가 정확히 같은 모양**이어야 합니다.

#### A-2. 원형 바디 — `btn_body_circle.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **192 × 192** |
| 형태 | 캔버스를 꽉 채우는 **정원** (사방 1px 여백) |
| 용도 | 원형 서브 버튼(UI 80×80)의 바디·림 |

#### A-3. 둥근 사각 글로우 — `btn_glow_rounded.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **192 × 192** |
| 형태 | A-1과 같은 둥근 사각형(반지름 28)을 중앙에 두고, **바깥으로 약 32px 퍼지는 빛번짐** |
| 알파 | 도형 가장자리 100% → **캔버스 가장자리 정확히 0%** |
| 안쪽 | 도형 안쪽도 100%로 채움 (속이 빈 링 아님) |
| 9-slice Border | **상·하·좌·우 모두 64** |
| 용도 | 네온 펄스 모드의 빛남, 바코드 스캔 성공 시 초록 승인 플래시 |

```
 알파:  0 ░░▒▒▓▓████████████▓▓▒▒░░ 0
        └32┘└── 둥근 사각 ──┘└32┘
```

- 지금은 바디 이미지를 반투명하게 겹친 것뿐이라 "빛나는" 느낌이 없습니다. 이 리소스가 들어오면 가장 체감이 큽니다.

#### A-4. 원형 글로우 — `btn_glow_circle.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **256 × 256** |
| 형태 | 지름 약 192px 원 + 바깥으로 32px 빛번짐 (A-3과 같은 방식) |
| 알파 | 캔버스 가장자리 정확히 0% |
| 용도 | 원형 서브 버튼의 글로우 |

### B. 이펙트

#### B-1. 배기 연기 — `fx_smoke_puff_01.png` ~ `fx_smoke_puff_03.png` (3종)

| 항목 | 값 |
|---|---|
| 캔버스 | **96 × 96** |
| 형태 | **뭉게구름 한 덩이** (작은 원 3~5개가 뭉친 실루엣). 3종은 모양만 조금씩 다르게 |
| 알파 | 가운데 약 90% → 가장자리로 부드럽게 0%. 덩어리 안쪽에 아주 옅은 명암(알파 차이) 정도는 허용 |
| 용도 | "9. 배송 출발" 모드. 버튼 왼쪽 아래에서 3~5개가 왼쪽 위로 뿜어져 나가며 커지고 사라짐 (UI 약 24×24 → 1.4배) |

- 완전한 원이면 비눗방울처럼 보입니다. **울퉁불퉁한 외곽**이 핵심입니다.
- 회색 틴트로 쓰니 흰색으로만 그려주세요.

| 항목 | 값 |
|---|---|

| 용도 | 배송 출발 순간 바퀴 쪽에서 튀는 짧은 섬광 (UI 30×4) |

```

 ╲  │  ─ ─ ─ 옅은 결 ─ ─ ─     │  ╱    ← 좌우 24px: 뜯긴 단면 (늘어나지 않음)
 ╱╲╱└──────────────────────────┘╲╱╲       가운데: 가로로 늘어남
```

### C. 아이콘

라벨에 쓰던 이모지(🚚📦🔥 등)가 한글 폰트(맑은 고딕)에 없어서 지금은 전부 지운 상태입니다. 그 자리를 아이콘으로 채웁니다.

| 항목 | 값 |
|---|---|
| 캔버스 | **96 × 96** |
| 안전 영역 | 캔버스 중앙 **72 × 72** 안에 도형을 넣을 것 |
| 형태 | **실루엣 한 색** (내부 디테일은 투명 구멍으로 표현, 그라데이션·외곽선 색 없음) |
| 시각 크기 | 아이콘끼리 크기감이 비슷하게 |
| 정렬 | 도형의 중심이 캔버스 중심에 오도록 |
| 표시 크기 | 글자 옆에 붙여서 씀. UI 약 18~36px (글자 크기와 같게) |

**토스트 요청서와 겹치는 아이콘은 그쪽 것을 그대로 씁니다 (새로 그리지 않음):**
`toast_icon_truck` (트럭), `toast_icon_box` (상자), `toast_icon_flame` (불꽃), `toast_icon_siren` (사이렌)

**새로 필요한 아이콘:**

| 파일명 | 쓰는 곳 | 표현 가이드 |
|---|---|---|
| `btn_icon_dispatch.png` | DISPATCH 버튼 | 큰 화물 트레일러 트럭 옆모습 (기존 트럭보다 길게, 바퀴 3개 이상) |
| `btn_icon_go.png` | 원형 배송 출발 버튼 (지금은 ▶) | 오른쪽 화살표 + 뒤에 속도선 2~3줄 |
| `btn_icon_hand_down.png` | 안내 문구 앞 | 아래를 가리키는 손가락 |
| `btn_icon_gamepad.png` | MOTION PRESETS 섹션 제목 | 게임패드 (십자키·버튼 구멍) |
| `btn_icon_sparkle.png` | ADD-ON FX 섹션 / 플로팅 텍스트 토글 | 큰 별빛 1개 + 작은 별빛 2개 |
| `btn_icon_wave.png` | 물결 리플 토글 | 말려 올라가는 파도 |
| `btn_icon_star.png` | 스파클 파티클 토글 | 꽉 찬 오각 별 |
| `btn_icon_gear.png` | SYSTEM 섹션 제목 | 톱니바퀴, 가운데 구멍 |
| `btn_icon_reset.png` | 초기화 버튼 | 원을 그리며 돌아가는 화살표 |

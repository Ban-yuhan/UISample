# 토스트 메시지(캡슐) UI 리소스 제작 요청서

원형 배지를 터치하면 캡슐로 펼쳐지는 토스트 메시지에 쓸 리소스 제작 요청입니다.
현재는 코드로 임시 스프라이트를 그려서 쓰고 있고, 이 요청서의 이미지로 교체합니다.

- 참고 이미지: `Assets/UI샘플/ResourceSheets/ToastMessageScene_SpriteSheet.jpg`
- 구현 코드: `Assets/Scripts/ToastMessage/CapsuleToastView.cs`

---

## 1. 공통 규칙

| 항목 | 내용 |
|---|---|
| 포맷 | PNG, 투명 배경 (RGBA) |
| 색상 | **전부 순백(#FFFFFF) 단색 + 알파만 사용.** 색은 코드에서 틴트합니다. 다른 색을 넣지 마세요. |
| 안티앨리어싱 | 가장자리는 부드럽게 (알파 그라데이션). 계단 현상 없을 것 |
| 여백 | 이미지 가장자리 1~2px는 투명으로 비울 것 (잘림 방지) |
| 크기 | 아래 각 항목의 **캔버스 크기를 정확히** 지킬 것 (2의 거듭제곱 또는 4의 배수 유지) |
| 파일명 | 아래 항목에 적힌 파일명 그대로 |

> 기준 해상도: UI 기준 캔버스에서 **캡슐 높이 54px**이 기본입니다. 아래 캔버스 크기는 이 54px 기준으로 약 2.4~4배로 잡았습니다. 비율만 맞으면 더 크게 그려도 되지만, 요청한 크기로 최종 납품해 주세요.

## 2. 완성 모습 (구도 참고)

### 접힌 상태 (원형)

```
        ┌──────── 글로우 76 ────────┐
        │    ╭──── 링 54 ────╮      │
        │    │  ╭─ 바디 54 ─╮│      │
        │    │  │   [아이콘 │      │
        │    │  │    26px]  │      │
        │    │  ╰───────────╯│      │
        │    ╰───────────────╯      │
        └───────────────────────────┘
        가로 54 × 세로 54 (원형)
```

### 펼친 상태 (캡슐)

```
 ╭────────────────────────────────────────────╮ 
 │ [아이콘]  제목 (14pt Bold)             (×) │  높이 54
 │  26px     서브 (11pt)                 22px │
 ╰────────────────────────────────────────────╯
 ◀──────────────── 가로 340 ─────────────────▶
 ◀─54─▶◀───────── 텍스트 영역 244 ──────────▶
```

- 원형(54×54) → 캡슐(340×54)로 **가로만 늘어납니다.** 세로는 54px 고정.
- 그래서 캡슐 바디와 외곽선은 **9-slice**로 제작합니다 (아래 3-1, 3-2).
- 레이어 순서 (아래 → 위): 글로우 → 링 → 캡슐 바디 → 글린트 → 아이콘 → 텍스트 → 닫기 버튼 → 외곽선

## 3. 제작 리소스

### 3-1. 캡슐 바디 — `toast_capsule_body.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **128 × 128** |
| 형태 | 캔버스를 꽉 채우는 **정원** (사방 1px 여백) |
| 9-slice Border | **상·하·좌·우 모두 64** (반지름 = 높이의 절반) |
| 용도 | 토스트 배경. 코드에서 톤별 색으로 틴트 |

```
 ┌────────────────┐   정사각형 캔버스 안에 꽉 찬 원.
 │    ▄▄████▄▄    │   가로로 늘렸을 때 양 끝은 반원,
 │  ▄██████████▄  │   가운데는 평평하게 늘어납니다.
 │  ████████████  │
 │  ▀██████████▀  │
 │    ▀▀████▀▀    │
 └────────────────┘
```

- 내부는 균일한 흰색 (그라데이션, 하이라이트, 그림자 넣지 말 것)
- 반지름이 정확히 캔버스 절반이어야 늘렸을 때 모양이 깨지지 않습니다.

### 3-2. 캡슐 외곽선 — `toast_capsule_outline.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **128 × 128** (바디와 동일) |
| 형태 | 바디와 같은 정원의 **테두리만** (안쪽은 완전 투명) |
| 선 두께 | 약 **6~7px** (UI 기준 약 3px) |
| 선 위치 | 바깥 가장자리에서 안쪽으로 **약 5px 띄움** (선이 잘리지 않도록) |
| 9-slice Border | **64** (바디와 동일) |
| 용도 | 바디 위에 겹쳐서 크림색(#FFFDF8)으로 틴트 |

- 바디와 겹쳤을 때 어긋나지 않도록 **중심과 반지름을 바디와 맞출 것.**

### 3-3. 아우라 링 — `toast_aura_ring.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **128 × 128** |
| 형태 | 얇은 **원형 링** (안쪽·바깥쪽 모두 투명) |
| 링 위치 | 바깥 지름 약 116px (캔버스 가장자리에서 약 6px 띄움) |
| 선 두께 | 약 **7px** (부드러운 가장자리) |
| 용도 | 접힌 상태에서 바깥으로 퍼져 나가는 물결 효과 (스케일 0.96 → 1.7배, 알파 페이드아웃) |

- 크게 확대되며 사라지는 용도라, 선이 너무 굵거나 선명하면 거칩니다.

### 3-4. 방사형 글로우 — `toast_aura_glow.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **128 × 128** |
| 형태 | 중심이 가장 밝고 가장자리로 갈수록 투명해지는 **방사형 그라데이션** |
| 알파 | 중심 100% → **가장자리 정확히 0%** (사각 경계가 보이면 안 됨) |
| 곡선 | 부드럽게 (smoothstep 느낌, 선형보다 중심이 조금 더 넓게) |
| 용도 | 원형 뒤에서 숨쉬듯 커졌다 작아지는 빛번짐 (UI 기준 76×76) |

> 참고: 캡슐로 펼쳐지면 이 글로우가 가로로 늘어난 타원이 됩니다. 별도 제작은 필요 없습니다.

### 3-5. 글린트 띠 — `toast_glint_strip.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **64 × 64** |
| 형태 | **가로 방향 그라데이션** 띠 (좌우 가장자리 0% → 중앙 100% → 0%). 세로 방향은 균일 |
| 용도 | 캡슐 안에서 대각선(-25°)으로 지나가는 반짝 빛 (UI 기준 22×90) |

```
 알파:  0 ░░▒▒▓▓████▓▓▒▒░░ 0     (가로 방향)
        └─────── 64px ──────┘     세로로는 전부 같은 값
```

- 가로 중앙이 가장 밝고, 양쪽 가장자리가 정확히 0%여야 합니다.

### 3-6. 닫기 버튼 배경 — `toast_close_bg.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **64 × 64** |
| 형태 | 캔버스를 꽉 채우는 **정원** (사방 1px 여백) |
| 용도 | 캡슐 오른쪽 닫기 버튼 배경 (UI 기준 22×22). 코드에서 검정 28% 알파로 틴트 |

### 3-7. 아이콘 세트 — `toast_icon_[이름].png`

| 항목 | 값 |
|---|---|
| 캔버스 | **96 × 96** |
| 안전 영역 | 캔버스 중앙 **72 × 72** 안에 도형을 넣을 것 (UI 기준 26×26 슬롯에 표시) |
| 형태 | **실루엣 한 색** (내부 디테일은 투명 구멍으로 표현, 그라데이션·외곽선 색 없음) |
| 시각 크기 | 아이콘끼리 크기감이 비슷하게 (한 아이콘만 작거나 크지 않게) |
| 정렬 | 도형의 중심이 캔버스 중심에 오도록 |

| 파일명 | 의미 | 표현 가이드 |
|---|---|---|
| `toast_icon_siren.png` | 긴급 알림 | 사이렌 돔 + 아래 받침 + 위쪽 빛줄기 3개 |
| `toast_icon_flame.png` | 불꽃 / 이벤트 | 불꽃 실루엣, 안쪽에 작은 구멍 |
| `toast_icon_warning.png` | 경고 | 삼각형 안에 느낌표를 구멍으로 |
| `toast_icon_bolt.png` | 번개 / 에너지 | 번개 모양 |
| `toast_icon_truck.png` | 배송 / 운송 | 트럭 옆모습 (화물칸 + 운전석 + 바퀴 2개) |
| `toast_icon_box.png` | 상자 / 입고 | 상자 + 테이프 홈 |
| `toast_icon_coin.png` | 재화 | 동전 + 안쪽 링 + 가운데 막대 |
| `toast_icon_coffee.png` | 휴식 / 일반 알림 | 컵 + 손잡이 + 김 2줄 |

> 실제로 쓸 종류만 납품해도 됩니다. 추가 아이콘이 필요하면 같은 규격으로 만들면 됩니다.

### 3-8. 닫기 X 아이콘 — `toast_icon_close_x.png`

| 항목 | 값 |
|---|---|
| 캔버스 | **48 × 48** |
| 형태 | 두 선이 교차하는 **X** (선 끝은 둥글게) |
| 크기 | X 전체가 캔버스 중앙 약 **24 × 24** 안에 들어올 것 |
| 선 두께 | 약 4px |
| 용도 | 닫기 버튼 배경 위에 흰색으로 표시 (UI 기준 10×10) |
